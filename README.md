# 공대 3호관 실내 길안내

군산대학교 공과대학 3호관(지하 1층 ~ 5층)의 실내 길안내 웹앱입니다.
사진 한 장으로 지금 어디에 있는지 알아내고, 3D 건물 모형 위에서 목적지까지 안내합니다.

- 졸업작품 · 김민종 · 손의윤 · 문성일
- 배포 : GitHub Pages — `index.html` + `aivec.js` 두 파일
- 설치 없이 폰 브라우저에서 동작합니다 (카메라·AI·글자 읽기 모두 브라우저 안에서)

## 어떻게 동작하나

```
사진 ──┬─▶ ① 글자 읽기 (Tesseract.js)
       │     호실 번호판 · 엘리베이터 층 표시 · 비상대피 안내판
       │     → 읽히면 그대로 확정 (오독 0건)
       │
       └─▶ ② 모양 비교 (MobileNetV2 α0.5, 1280차원)
             사진 1,753장으로 만든 기준벡터 4,847개와 비교
             → 상위 후보 + 확신도 + 복도 좌우
                    │
                    ▼
            ③ 관리자 승인 ── 승인하면 모든 기기가 배운다 (Firestore)
```

글자가 읽히면 글자를 믿고, 안 읽히면 모양으로 추정하되 **확정은 사람이 합니다.**
AI 가 틀린 위치를 스스로 배워 나빠지는 것을 막기 위해서입니다.

## 정확도

**다른 사람이 찍은 사진으로만** 잽니다. 같은 사람이 한 번에 찍은 사진(36개 묶음)은
기준에서 빼고 맞힙니다. 처음 온 사용자는 우리가 찍은 사진을 갖고 있지 않기 때문입니다.

| 종류 | 장수 | 정확한 자리 | 층 | 5등 안 |
|---|---:|---:|---:|---:|
| 전체 (강의실 제외) | 1,522 | 53.3% | 65.5% | 82.4% |
| 복도 | 920 | 55.3% | 67.2% | 82.7% |
| 라운지·로비 | 179 | 64.2% | 79.9% | 84.9% |
| 복도 — 같은 자리에서 두 장 | 909 | 61.9% | 73.8% | 88.2% |

글자 읽기 (오독 0건) : 복도 번호판 37% · 엘리베이터 안 층 97% · 비상대피 안내판 층 45%

측정 : `eval_all.html` 을 열고 「전체 측정 시작」 — 94초.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 원본 (3D·AI·글자 읽기·건의함 전부). **기능 패치는 여기에 건다** |
| `도구/patch_v*.ps1` | 기능 패치. 번호 순서대로 원본에 한 번씩 적용된 기록 |
| `도구/patch_v58.ps1` | 빌드 — 원본 + 기준벡터 → 배포용 `index_new.html` + `aivec.js` |
| `gen.html` | 사진 → 기준벡터 생성 (`생성물/aivec_new.json`, 약 7분) |
| `eval_all.html` | 정확도 측정 — 발표 숫자 전부 |
| `eval_audit.html` | 사진 배치 감사 — 폴더를 잘못 들어간 사진 찾기 |
| `ocrtest.html` | 글자 읽기 측정 |
| `batches.json` | 사진 1,753장 → 촬영 묶음(층·파일계열·기기). 측정의 기준 |
| `preview.ps1` | 미리보기 서버 (http://localhost:8080) |
| `lib/` | Tesseract.js · TensorFlow.js (인터넷 없이도 동작하도록) |
| `*.txt` | 측정 결과·작업 기록·촬영 안내 |

사진(2.9GB)은 저장소에 넣지 않습니다. 사진 이름 목록은 `batches.json` 에 있습니다.

## 빌드

```
1. preview.ps1 실행                     (미리보기 서버)
2. http://localhost:8080/gen.html       「생성 시작」 → 생성물/aivec_new.json
3. pwsh -File 도구/patch_v58.ps1        → index_new.html + aivec.js
4. http://localhost:8080/eval_all.html  「전체 측정 시작」
```

코드가 안 바뀌었으면 `index_new.html` 은 바이트 단위로 같게 나옵니다.
