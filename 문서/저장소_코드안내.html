3.1 안전망(golden)이 무엇인가

앱을 크게 고치기 전에 지금 앱이 내는 결과를 전부 기록해 두고, 고친 뒤 같은 방법으로 돌려 한 글자·한 점까지 비교합니다. 기록하는 것은 세 가지입니다.

무엇기록하는 내용
logic모든 목적지 × 출발층의 길안내 문장(한/영), 152곳의 3D 위치·이름·층·접수 범위, 관리자 장소 목록, 사진 설명, 층 배치, 길찾기 경로, 코드 읽기 함수
photos앱에 들어 있는 사진 파일의 바이트 지문 — 사진을 파일로 빼내도 같은 사진인지 확인
dom화면의 모든 id, 글자, 요소마다의 계산된 CSS 값
왜 만들었나 — 코드가 2만 줄을 넘으니 어디를 고치면 어디가 깨지는지 알 수 없게 되었습니다. 실제로 길안내 문장 하나가 조용히 바뀐 적이 있었습니다. 글자는 눈으로 못 잡습니다. 그래서 기계가 전부 대조하게 만들었습니다.
교수님 : 「시험은 어떻게 하셨나요?」
→ 「자동 검사 22가지와 안전망이 있습니다. 안전망은 고치기 전 결과를 816개 파일로 기록해 두고, 고친 뒤 한 글자·한 점까지 비교합니다. 그리고 검사를 통과하지 못하면 사이트가 바뀌지 않도록 배포 길목에 박아 두었습니다.」
