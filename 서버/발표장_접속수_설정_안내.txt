왜 하나
  · 발표장 QR(발표 자료 20쪽)을 찍으면, 휴대폰이 서버의 숫자 하나(live/grad)를 1 올리고
    곧바로 앱(동문에서 시작)으로 넘어갑니다. 발표 화면은 그 숫자를 1.5초마다 읽어 보여 줍니다.
  · 지금 서버 규칙은 「그 밖의 모든 곳은 막는다」라서, 이 숫자 칸을 새로 열어 주어야 합니다.
  · 새 규칙이 허락하는 것 : 누구나 숫자를 읽기 · 1 씩 올리기만. 줄이거나 지울 수 없고,
    누가 열었는지(이름 · 기기 정보)는 남지 않습니다 — 숫자 n 과 마지막 시각 t 뿐입니다.
  · 다른 칸(제보 · 하루 3번 · 사진 · 방 정보 · 관리자)의 규칙은 한 글자도 바뀌지 않았습니다.

----------------------------------------------------------------
1. 새 규칙 붙이기                                         (2분)
----------------------------------------------------------------
  왼쪽 메뉴 Firestore Database → 맨 위 「규칙(Rules)」 탭
  → 지금 적혀 있는 것을 모두 지우고, 같은 폴더의 「규칙_붙여넣기용.txt」 내용을 통째로 붙여 넣기
  → [게시(Publish)]
  (규칙_붙여넣기용.txt 와 firestore.rules 는 같은 내용입니다 — 141줄)

----------------------------------------------------------------
2. 되는지 확인                                            (1분)
----------------------------------------------------------------
  ① 컴퓨터에서 https://minjong0910.github.io/live/ 를 엽니다.
     왼쪽 아래가 「서버 규칙이 아직 없습니다」(분홍 글씨) → 「● 서버 연결됨」(회색 글씨)으로 바뀌면 규칙이 들어간 것입니다.
  ② 휴대폰 카메라로 화면 가운데 「발표장」 QR 을 찍습니다 → 앱이 열리고, 컴퓨터 화면 숫자가 1 올라갑니다.
  ※ 같은 휴대폰은 3시간에 한 번만 셉니다. 리허설 때 찍은 폰은 3시간이 지나야 다시 셉니다.
  ※ 발표 화면은 「연 때의 숫자」를 0 으로 삼습니다. 리허설 숫자가 남아 있어도, 발표 때 LIVE 를 누르면 0 부터 셉니다.
     (화면에서 R 키 = 다시 0 부터 · 처음부터 센 전체 수는 왼쪽 아래 작은 글씨에 나옵니다)
