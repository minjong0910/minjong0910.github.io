 측정 도구 돌리는 법 — 혼자서 처음부터 끝까지
================================================================

■ 준비 (딱 한 번)

  D:\군산대\미리보기_실행.bat  을 더블클릭합니다.
  검은 창이 뜨고 브라우저가 자동으로 열립니다.
  이 창은 켜 둔 채로 두세요. 닫으면 도구가 안 돌아갑니다.

  주소가 localhost:8080 인지 확인하세요.
  8081 이면 서버가 두 개 떠 있는 것입니다 — 검은 창을 전부 닫고 다시 하세요.


■ 도구 세 가지

  주소창에 아래를 입력하면 열립니다.

  ┌──────────────────────────────────┬──────────────────────────┐
  │ http://localhost:8080/eval.html  │ 1차 측정 (기본 비교 20가지) │
  │ http://localhost:8080/eval2.html │ 2차 측정 (표지판 크롭 포함) │
  │ http://localhost:8080/gen.html   │ 새 기준 데이터 만들기       │
  └──────────────────────────────────┴──────────────────────────┘

  전부 [측정 시작] 또는 [생성 시작] 버튼 하나만 누르면 됩니다.
  1~3분 걸립니다. 진행 막대와 기록이 화면에 나옵니다.


■ 무엇이 나오나

  eval.html   전처리 5가지 x 후처리 4가지 = 20가지 조합을 비교
              화면에 표가 나오고, 결과가 파일로도 저장됩니다
              → D:\군산대\생성물\eval1_result.json

  eval2.html  표지판 크롭 · 확대 배율 · 주성분 제거까지 비교 (12조합 x 5)
              장소를 두 조각으로 나눠 교차 검증하므로 더 믿을 만합니다
              → D:\군산대\생성물\eval2_result.json

  gen.html    앱에 넣을 새 기준벡터를 만듭니다
              → D:\군산대\생성물\aivec_new.json


■ 사진을 더 넣은 뒤에 하는 순서

  1) D:\군산대\사진원본\ 에 새 사진 폴더를 넣는다
  2) eval2.html 로 정확도를 다시 잰다        (숫자가 얼마나 올랐는지 확인)
  3) gen.html 로 새 기준 데이터를 만든다
  4) 아래 명령으로 앱에 반영한다

       pwsh -File D:\군산대\도구\patch_v58.ps1

     → index.html 을 읽어 index_new.html 을 새로 만듭니다
  5) 흐름·문구 수정도 다시 입힌다

       pwsh -File D:\군산대\도구\patch_v59.ps1  D:\군산대\index_new.html
       pwsh -File D:\군산대\도구\patch_v59b.ps1 D:\군산대\index_new.html
       pwsh -File D:\군산대\도구\patch_v60.ps1  D:\군산대\index_new.html
       pwsh -File D:\군산대\도구\patch_v61.ps1  D:\군산대\index_new.html

  6) http://localhost:8080/index_new.html 에서 직접 써 보고 확인
  7) 괜찮으면 index_new.html 을 index.html 로 이름 바꿔 GitHub 에 올린다


■ JSON 파일을 여는 법

  메모장으로 열면 한 줄로 길게 보여 읽기 어렵습니다.
  크롬 주소창에 파일을 끌어다 놓으면 보기 좋게 펼쳐집니다.

  또는 도구 화면의 [결과 JSON 보기] 버튼을 누르면 새 탭에 나옵니다.


■ 잘 안 될 때

  "사진 목록을 못 불러왔습니다"
    → 미리보기_실행.bat 이 켜져 있는지 확인. 주소가 localhost:8080 인지 확인.

  버튼을 눌러도 "모델 준비 중…" 에서 멈춤
    → 인터넷 연결을 확인하세요. AI 모델을 인터넷에서 받아옵니다.
      D:\군산대\lib\ 와 model\ 이 있으면 인터넷 없이도 되지만 조금 느립니다.

  중간에 멈춘 것 같음
    → 사진 240장에 1~3분 걸립니다. 진행 막대가 움직이면 정상입니다.

  결과가 이상함
    → D:\군산대\서버기록.txt 를 열어보면 무엇이 오갔는지 남아 있습니다.
