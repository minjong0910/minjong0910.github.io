사진 직접 고르기 — 조원들에게 보낼 안내
===========================================================
만든 날 : 2026-09-26


■ 조원들에게 보낼 주소

      https://minjong0910.github.io/pick/

  링크만 보내면 됩니다. 프로그램을 깔 것도, 파일을 받을 것도 없습니다.
  컴퓨터·휴대폰 아무거나 됩니다. (사진이 많으니 와이파이에서 하시는 게 좋습니다)


■ 들어 있는 것

  · 장소 152곳 · 찍어 둔 사진 2,075장 전부
  · 장소마다 맨 앞에 노란 「지금 쓰는 사진」 표 — 지금 앱에 들어 있는 사진입니다


■ 두 사람이 나눠서 하기

  화면을 열면 맡은 곳을 고르는 단추가 먼저 나옵니다. 사진 수가 비슷하게 갈립니다.

      가  —  지하 1층 · 1층 · 2층 · 3층      (장소 93곳 · 사진 1,187장)
      나  —  4층 · 5층                       (장소 59곳 · 사진 888장)

  바로 들어가게 하려면 주소 끝에 #A / #B 를 붙여 보내셔도 됩니다.

      https://minjong0910.github.io/pick/#A      ← 「가」 맡은 사람
      https://minjong0910.github.io/pick/#B      ← 「나」 맡은 사람


■ 고르는 법 (조원에게 그대로 전달하셔도 됩니다)

  ① 장소마다 마음에 드는 사진 한 장을 누릅니다 → 파란 테두리가 생깁니다
  ② 다시 누르면 취소됩니다
  ③ 노란 「지금 쓰는 사진」이 제일 낫다면 그걸 누르시면 됩니다 (= 그대로 두기)
  ④ 사진을 오른쪽 클릭(휴대폰은 길게 누르기)하면 크게 볼 수 있습니다
  ⑤ 사진이 많은 곳은 처음 24장만 보입니다 — 아래 「나머지 N장 더 보기」를 누르면 전부 나옵니다
  ⑥ 위쪽 「아직 안 고른 곳만」 을 누르면 남은 곳만 보입니다
  ⑦ 고른 것은 자동으로 저장됩니다. 창을 닫았다 나중에 다시 열어도 그대로 있습니다
  ⑧ 다 되면 위쪽 「고른 것 저장 ↓」 → 고른사진_가.txt (또는 고른사진_나.txt) 가 내려받기 폴더에 생깁니다
  ⑨ 그 파일을 김민종에게 보냅니다

  ※ 전부 고를 필요는 없습니다. 바꾸고 싶은 곳만 고르면 나머지는 지금 사진이 그대로 남습니다.


■ 파일을 받은 뒤 (김민종이 할 일)

      pwsh -File 도구\고른사진_넣기.ps1 -Pick "...\고른사진_가.txt","...\고른사진_나.txt"
      pwsh -File 도구\오프라인목록.ps1
      pwsh -File 검사.ps1 -Full
      git add -A ; git commit ; git push origin main

  · 두 파일을 한 번에 줘도 되고, 하나씩 줘도 됩니다. 안 주면 내려받기 폴더에서 고른사진*.txt 를 알아서 찾습니다.
  · 넣기 전에 무엇이 바뀌는지만 보려면 -WhatIfOnly 를 붙입니다.
  · 사진은 앱에 넣을 때 긴 변 900 픽셀로 줄여 굽습니다 (지금 앱 사진과 같은 규격).


■ 알아두실 점

  · 건물 외부(정문·후문·동문·서문) 8장은 이 화면에 없습니다.
    문마다 안/밖 자리가 정해진 한 묶음이라 '한 장 고르기'가 성립하지 않습니다.
    바꿔야 하면 어느 문의 어느 사진인지 말씀해 주시면 그 자리만 바꿉니다.

  · 복도·엘리베이터처럼 사진만 봐서는 층을 알 수 없는 곳은,
    파일 이름 맨 앞의 「3층-」 이 그 층입니다.

  · 이 고르기 화면(site\pick\)은 앱의 오프라인 저장 목록에서 빠져 있습니다.
    앱 사용자가 이 사진 41MB 를 내려받는 일은 없습니다.

  · 고르기가 끝나면 site\pick\ 폴더를 지워도 됩니다 (앱과 무관합니다).


■ 다시 만들어야 할 때

  사진원본\ 에 사진을 더 넣었거나 앱 사진이 바뀌었으면

      pwsh -File 도구\사진고르기_만들기.ps1          (이미 구운 미리보기는 건너뜀)
      pwsh -File 도구\사진고르기_만들기.ps1 -Force   (전부 다시 굽기)
