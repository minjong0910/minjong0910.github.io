■ 고르는 법

  ① 장소마다 마음에 드는 사진 한 장을 누릅니다 → 파란 테두리가 생깁니다
  ② 다시 누르면 취소됩니다
  ③ 노란 「지금 쓰는 사진」이 제일 낫다면 그걸 누르시면 됩니다 (= 그대로 두기)
  ④ 그 자리에 다른 곳 사진을 넣고 싶으면 「전체 사진에서 고르기 …」
     → 위쪽 칸에 장소 이름·코드·파일 이름을 쳐서 찾고 → 사진을 누르면 그 자리에 들어갑니다
     (그렇게 넣은 사진에는 보라색으로 「○○에서」 표가 붙습니다)
  ⑤ 사진을 오른쪽 클릭(휴대폰은 길게 누르기)하면 크게 볼 수 있습니다
  ⑥ 사진이 많은 곳은 처음 24장만 보입니다 — 아래 「나머지 N장 더 보기」를 누르면 전부 나옵니다
  ⑦ 위쪽 「아직 안 고른 곳만」 을 누르면 남은 곳만 보입니다
  ⑧ 고른 것은 자동으로 저장됩니다. 창을 닫았다 나중에 다시 열어도 그대로 있습니다
     (예전 판에서 고르던 것이 있으면 그대로 이어집니다)
  ⑨ 다 되면 위쪽 「고른 것 저장 ↓」 → 고른사진.txt 가 내려받기 폴더에 생깁니다

  ※ 전부 고를 필요는 없습니다. 바꾸고 싶은 곳만 고르면 나머지는 지금 사진이 그대로 남습니다.


■ 고른 파일을 앱에 넣기

      pwsh -File 도구\고른사진_넣기.ps1 -Pick "...\고른사진.txt"
      pwsh -File 도구\오프라인목록.ps1
      pwsh -File 검사.ps1 -Full
      git add -A ; git commit ; git push origin main

  · -Pick 을 안 주면 내려받기 폴더에서 고른사진*.txt 를 알아서 찾습니다. 여러 개를 줘도 됩니다.
  · 넣기 전에 무엇이 바뀌는지만 보려면 -WhatIfOnly 를 붙입니다.
  · 사진은 앱에 넣을 때 긴 변 900 픽셀로 줄여 굽습니다 (지금 앱 사진과 같은 규격).
  · 사진을 바꾸면 안전망 기록이 달라집니다 — 검사가 [실패]로 알려 주면 확인한 뒤
    tests\run_golden.ps1 -Mode capture 로 새 기준을 담고 세 곳의 기본 태그를 올립니다.


■ 고른사진.txt 의 형식

      <코드><탭><고른 사진>

      EVIN2            (그대로)               ← 지금 쓰는 사진 그대로 (아무것도 안 함)
      HALL3L           3층-HALL3L-복도-왼쪽.jpg   ← 그 장소 폴더의 사진
      GATE_EAST_OUT    BLD/06.jpg             ← **다른 장소**에서 가져온 사진

  세 번째 줄이 2026-09-28 에 늘어난 형식입니다.
  다른 곳에서 가져온 사진은 그 자리 폴더(site\data\photos\<코드>\01.jpg)로 복사되고,
  photos.js 의 주소도 그 자리로 함께 바뀝니다 — 이걸 안 하면 화면은 옛 사진 그대로입니다.

  · 복도·엘리베이터처럼 사진만 봐서는 층을 알 수 없는 곳은,
    파일 이름 맨 앞의 「3층-」 이 그 층입니다.

  · 이 고르기 화면(site\pick\)은 앱의 오프라인 저장 목록에서 빠져 있습니다.
    앱 사용자가 이 사진 41MB 를 내려받는 일은 없습니다.

  · 고르기가 끝나면 site\pick\ 폴더를 지워도 됩니다 (앱과 무관합니다).
