# 번호판 읽기(OCR)로 위치·층 알아내기 — 적용 안내 (v53)

**기준** v52 → `index.html` (v53, +13KB) + 서버에 `lib/tess/` 폴더 추가 (10MB)
**해결한 문제** 5층 복도 사진을 올렸는데 4층 복도로 나오던 것 · 다른 구도로 찍으면 안 맞던 것

---

## 1. 왜 복도만 계속 틀렸나

복도·엘리베이터 앞은 **어느 층이나 똑같이 생겼습니다.** 바닥 타일, 천장, 문 배치가 전부 같아서, 사진의 생김새만 보는 AI(CNN)는 원리적으로 층을 구분할 수 없습니다. 4층 사진과 5층 사진의 차이는 게시판 종이나 사물함 같은 우연한 물건뿐이라, 조금만 다른 자리에서 찍으면 다른 층이 1등으로 나옵니다.

그래서 말씀하신 대로 **벽에 붙은 호실 번호판을 읽게** 했습니다. `13512`가 읽히면 5층은 확실합니다.

## 2. 고친 것

1. **번호판 읽기(OCR)** — 제보 사진에서 숫자만 읽어 호실 번호(`13xyz`)를 찾습니다.
   - 강의실 사진이면 → **그 방으로 확정** (예: 13501 번호판 → 13501호)
   - 복도·엘리베이터 사진이면 → **그 층의 복도·엘베 후보를 맨 위로**, 층 확정 (예: 13512 번호판 → 5층 복도)
   - 번호가 여러 개 읽히면(옆방 문패까지) 사진 판별 1등과 같은 것을 고릅니다.
   - 멀리 있는 작은 번호판용으로 사진을 4조각으로 나눠 2배 확대해 다시 읽습니다.
2. **"몇 층에서 찍으셨나요?" 버튼** — 제보 화면에 B1·1~5 버튼. 누르면 메모에 `5층`이 붙고, AI가 그 층 후보를 위로 올립니다. 번호판이 안 보이는 복도 사진의 안전장치입니다.
3. **버그 수정** — 제보 메모가 AI 판정에 **전달되지 않고 있었습니다** (v45부터). "2층 복도"라고 써도 힌트로 안 쓰였던 이유입니다. 이제 실제로 반영됩니다.
4. **층 힌트를 전체 순위에서 찾음** — 상위 8개 안에 그 층 후보가 없어도 반드시 올라옵니다.
5. **촬영 안내문** — "복도·엘리베이터는 가까운 호실 번호판이 함께 나오게 찍어 주세요."

## 3. 측정

**번호판 읽기 (앱 내장 강의실 사진 104장, 번호판이 찍힌 것 기준)**

| 방식 | 번호를 정확히 읽음 | 엉뚱한 번호로 읽음 |
|---|---|---|
| 사진 전체 한 번 | 24장 | 0 |
| **전체 + 4조각 확대 (채택)** | **50장** | **0** |

**전체 판정 (실제 앱 코드, 같은 사진·같은 변형 268건)**

| | v51 | v52 | **v53** |
|---|---|---|---|
| top-1 정확도 | 74.6% | 90.7% | **94.0%** |
| 호실 | 69.3% | 88.2% | **92.5%** |
| 복도·엘리베이터·출입문·지하 | 90~100% | 100% | **100%** |
| 자동 확정 비율 / 그중 정답 | 53% / 95.7% | 78% / 99.5% | **85% / 98.7%** |

복도 사진에 번호판 `13512`를 합성해 넣은 시험: 번호판 없이 → 4층 복도, 번호판 있음 → **5층 우측 복도**, 후보 3개 전부 5층.

## 4. 올리기 — 이번엔 파일이 둘

1. `index.html` 덮어쓰기
2. **`b3nav_OCR_추가파일.zip`을 풀어 `lib/tess/` 폴더를 저장소에 올리기** (lib 폴더 안에 tess 폴더, 파일 5개). 예전에 lib/, model/ 올린 것과 같은 방법.
   - 이 폴더가 없으면 공개 CDN에서 받아 쓰고, 그것도 안 되면 OCR 없이(v52와 같게) 판정합니다. 앱이 멈추진 않습니다.
3. `?v=53`으로 열기

## 5. 확인하기

1. 건의함 화면에 들어가면 "AI 준비 완료" 뒤에 OCR 파일을 미리 받습니다 (10MB, 한 번만 — 다음부터는 브라우저에 저장됨).
2. **5층 복도**를 가까운 호실 번호판이 보이게 찍어 올리기 → 카드에 `🔢 번호판 135xx → 5층`, 관리자 화면에 `층 : 5층 (사진 속 번호판에서 읽음)`
3. 번호판 없이 찍고 **층 버튼 5**를 누른 뒤 올리기 → 메모에 `5층`이 붙고 5층 후보가 1등
4. 강의실 문을 번호판이 보이게 찍기 → 그 방으로 바로 확정

## 6. 정직한 한계

- **번호판이 안 찍힌 복도 사진은 여전히 층을 알 수 없습니다.** 어떤 AI도 똑같이 생긴 두 층을 사진만으로 가르진 못합니다. 그래서 층 버튼과 촬영 안내를 같이 넣었습니다.
- 번호판이 너무 작으면(사진에서 글자 높이 10픽셀 아래) 못 읽습니다. 사진 절반 크기 정도까지 줄여도 읽히는 걸 확인했지만, 그보다 멀면 안 됩니다.
- OCR은 제보할 때만 돌고, 폰에서 2~5초쯤 걸립니다 (별도 워커라 화면은 안 멈춤). 길안내만 쓰는 사람은 영향 없습니다.
- "다른 구도로 찍어도 맞히기"는 v52의 3시점 기준벡터가 맡고 있고 이번 측정에서 92%입니다. 더 올리는 가장 확실한 방법은 **방마다 각도가 다른 사진을 2~3장 등록**하는 것입니다(AI가 자동으로 학습).
