# AI 사진 파악 자료집 — 사진 239장 내장 · 컴퓨터에서 넣고 빼기 (v56)

**기준** v55 → `index.html` (v56, 18.9MB — 자료집 1.97MB 포함)
**할 일** GitHub 저장소의 `index.html` 을 이 파일로 덮어쓰기 — 그것뿐입니다.

---

## 1. 이번에 된 것

보내주신 `공대3호관_사진정리_v12` ZIP의 **사진 239장(위치 123곳)** 을 앱 파일 안에 **기본 자료집**으로 담았습니다.
이제 **모든 사용자의 폰**에서 AI가 이 239장을 기준으로 위치를 알아봅니다. (v55까지는 자료집이 관리자 폰 한 대에만 있었습니다)

| | 장수 |
|---|---|
| 지하 1층 (크리에이티브 존 · 엘리베이터 안) | 4 |
| 1층 ~ 5층 호실 (13101 ~ 13524, KTC) | 203 |
| 복도 좌·우 (HALL1L ~ HALL5R) | 10 |
| 엘리베이터 (EV1 ~ EV5, 안·앞) | 6 |
| 화장실 (WC1 ~ WC5) | 5 |
| 출입문 (정문·후문·동문·서문 외관·안쪽, BLD) | 11 |

`사진목록.csv` 와 대조해 239장 전부 같은 위치로 들어갔습니다. (`EVB1` 만 앱에 없는 코드라 `B1`(지하 1층)으로 넣었습니다)

## 2. 효과 — 실제로 재봤습니다

보내주신 239장을 **조금 잘라내고 옮기고 밝기를 바꿔**(실제 제보처럼) AI에게 물어봤습니다.

| | v55 (자료집 없음) | **v56 (239장 내장)** |
|---|---|---|
| 1위가 정답 | 26.8% | **99.2%** |
| 3위 안에 정답 | 33.9% | **100%** |
| 층을 틀림 | 127장 | **0장** |

남은 2장은 번호판 OCR이 옆방 번호(13310→13319)로 읽은 경우입니다.

솔직하게 덧붙이면, **그 사진 자체를 빼고**(= 완전히 처음 보는 각도) 물어보면 28.9%로 v55와 비슷합니다.
호실 문 사진은 방마다 똑같이 생겨서 **번호판을 읽어야만** 구분되는데, 비스듬히 찍은 사진은 OCR이 37%만 읽습니다.
그래서 자료집의 진짜 힘은 **"찍어둔 자리 근처에서 찍은 사진은 거의 확실히 맞힌다"** 는 것입니다.
각 방을 왼쪽·오른쪽 두 자리에서 찍어 두신 게 그래서 잘 맞는 방향이고, 자주 제보가 들어오는 곳은 자리를 하나 더 늘리면 됩니다.

## 3. 컴퓨터(노트북)에서 사진 넣고 빼기

로고 5번 탭 → 7자리 → **사진 등록** → **🤖 AI 사진 파악 자료집**

**넣기** — 사진이나 폴더째 압축한 ZIP을 화면의 점선 상자에 **끌어다 놓기** → 목록 확인 → **이대로 자료집에 넣기**
- 보내주신 정리 방식 그대로 알아봅니다 : `5층/13524_PC실/…`, `1층-HALL1L-복도-왼쪽.jpg`, `3층-화장실.jpg`, `1층-정문 외관.jpg`, `지하1층-후문-….jpg`
- 이름 끝의 `-왼쪽` `-오른쪽` `(창가)` 는 **각도**로 기억되고, 출입문·지하는 `정문 외관` `후문 크리에이티브 존 통로` 처럼 설명이 남습니다
- 새로 넣은 사진은 **노란 테두리** = "아직 이 컴퓨터에만 있음"

**빼기** — 사진의 **✕** 또는 위치 카드의 **이 위치 전부 빼기**
- 파일에 담긴 기본 사진을 빼면 **이 컴퓨터에서 숨김**이 되고, 아래 **숨긴 기본 사진 되돌리기** 버튼으로 언제든 복구됩니다

**모두에게 적용** — 맨 아래 **📥 자료집을 담은 index.html 내려받기**
1. 지금 보이는 자료집(기본 + 새로 넣은 것, 뺀 것은 제외)이 담긴 `index.html` 이 내려받아집니다
2. GitHub 저장소에서 `index.html` 을 이 파일로 **덮어쓰기** (지금까지 하던 그대로)
3. 1~2분 뒤부터 모든 폰의 AI가 새 자료집을 씁니다

내려받은 파일을 같은 컴퓨터에서 다시 열어도 사진이 두 번 잡히지 않게 자동으로 정리됩니다.
길안내 화면의 사진·3D·기존 AI 학습은 그대로 유지됩니다.
