## 1. 가장 중요한 것 — 더블클릭으로 열면 기능이 안 됩니다

`index.html` 을 더블클릭해서 열면 주소가 `file:///...` 이 됩니다.
브라우저는 이 주소를 **"안전한 주소"로 쳐주지 않습니다.** 파일 안의 판정 코드가 이렇습니다.

```javascript
function secure(){
  return window.isSecureContext ||
         location.protocol==='https:' ||
         location.hostname==='localhost' || location.hostname==='127.0.0.1';
}
```

`file://` 은 네 조건에 하나도 걸리지 않습니다. 그래서 아래가 **전부 막힙니다.**

| 기능 | 막히는 이유 |
|---|---|
| QR 찍고 시작 | 카메라를 켤 수 없음 |
| 사진 위치 판별 AI | AI 모델을 인터넷에서 못 받아옴 |
| 번호판 OCR | 글자 인식 라이브러리를 못 받아옴 |
| 서버 연동 · 7자리 로그인 | Firebase가 `file://` 출처를 거부 |
| 관리자 화면(스크롤·사진 크게 보기) | 로그인을 통과해야 들어가는 화면이라 같이 막힘 |

**기능이 사라진 게 아닙니다.** 파일에는 다 들어 있고, 주소만 바꿔주면 전부 살아납니다.

- 올린 뒤 확인 : https://minjong0910.github.io/
- 올리기 전 확인 : `미리보기_실행.bat` 더블클릭 → 열리는 `http://localhost:8080/`
  (`localhost` 는 위 조건에 걸리므로 카메라·AI·OCR·로그인이 전부 됩니다)

## 2. 배포하는 법

`index.html` 을 GitHub 저장소 `minjong0910.github.io` 에 덮어쓰면 끝입니다.

1. 저장소에서 **Add file → Upload files**
2. `index.html` 을 끌어다 놓기 (이름이 같으므로 덮어쓰기)
3. **Commit changes**

파일 이름은 반드시 `index.html` 이어야 합니다. 1~2분 뒤 반영되고,
안 바뀌어 보이면 `Ctrl+Shift+R` 로 새로고침하세요.

## 4. 자료집에 사진을 더 넣고 싶을 때

앱에서 하는 게 가장 쉽습니다. 로고 5번 탭 → 7자리 → **사진 등록** →
**🤖 AI 사진 파악 자료집** 에서 사진이나 ZIP을 끌어다 놓고,
맨 아래 **「📥 자료집을 담은 index.html 내려받기」** 를 누르면 새 `index.html` 이 받아집니다.
그 파일을 `D:\군산대\index.html` 에 덮어쓰고 GitHub에도 올리면 됩니다.

## 7-1. 미리보기 창에 뜨는 글씨

- `200 / (19.2 MB)` — 정상입니다. 파일을 잘 내보냈다는 뜻입니다.
- `404 /favicon.ico` — 브라우저가 탭 아이콘을 찾는 것뿐입니다. 무시해도 됩니다(이제 표시하지 않습니다).
- `404 /lib/... /model/...` — **이제 안 납니다.** 앱이 AI·글자인식 파일을 내 PC에서 먼저 찾는데,
  예전에는 그 파일이 없어 인터넷에서 받아왔습니다. 지금은 풀어 두어 바로 찾습니다.
