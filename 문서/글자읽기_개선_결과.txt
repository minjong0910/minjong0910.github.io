글자 읽기 개선 결과 (v66, 2026-09-20)
================================================================

한 줄 요약
  사진 모양만으로는 층을 못 가르는 곳(복도·엘리베이터 안·비상대피 안내판)에서
  사진 속 글자(호실 번호 · 엘리베이터 층 표시 · 안내판 제목의 "N층")를 읽어 층을 정한다.
  세 가지 모두 시험한 사진에서 "틀린 층을 말한 경우"는 0장이다.


────────────────────────────────────────────────────────────────
 1. 결과 (실측)
────────────────────────────────────────────────────────────────

                          시험 장수   예전        지금        틀림
  복도 호실 번호판           60장    9장 (15%)   22장 (37%)    0
  엘리베이터 안 층 표시       30장    11.5% *     29장 (97%)    0
  비상대피 안내판 "N층"       51장    21.6% *     23장 (45%)    0

  * 예전 = 글자를 안 읽고 사진 모양만으로 정확한 자리를 맞힌 비율
    (다른 조원이 찍은 사진으로 맞히는 현실적인 시험)

  번호판을 읽으면 호실까지 나오므로 층과 왼쪽/오른쪽 복도가 함께 정해진다.
  (예 : 13326 → 3층 왼쪽 복도)
  읽지 못한 사진은 예전처럼 사진 모양으로 판정한다 — 나빠지는 경우는 없다.


────────────────────────────────────────────────────────────────
 2. 무엇이 문제였고 어떻게 고쳤나
────────────────────────────────────────────────────────────────

  [복도 번호판]
    문제 : 사람 눈에는 13209 가 또렷한데 글자 인식기(tesseract)가 못 읽었다.
           인식 모델을 바꿔도(빠른/기본/정밀), 기울기를 돌려도 결과가 같았다.
           원인은 글자 모양이 아니라 "글자 줄 찾기" — 번호 옆의 KSNU 로고 띠,
           종이 테두리가 같이 들어가면 줄을 못 찾는다.
    해결 : 파란 판 둘레에서 키가 비슷하고 한 줄로 늘어선 덩어리(숫자)만 찾아,
           그 픽셀만 흰 바탕에 검게 다시 그리고 기울기를 바로잡아 "한 줄"로 읽힌다.

  [엘리베이터 안]
    문 위와 버튼판의 층 표시기(검은 판 위에 빛나는 보라색 숫자)를 읽는다.
    · 폰마다 색이 다르게 찍힌다 (보라 / 아이폰은 파랑에 가까움) → 색 대신
      "파랑이 세고 초록이 약한 밝은 점 + 둘레가 어두움" 으로 찾는다
    · 화살표(↓)를 "4" 로 읽는다 → 화살표 모양·자리(숫자 왼쪽/위)로 거른다
    · 글자가 너무 크면 인식기가 빈칸을 낸다 → 높이 30픽셀로 맞춘다
    · 가장 큰 위험 : 엘리베이터 "앞(바깥)" 의 표시기는 엘리베이터 칸이 있는
      층을 보여 준다. 읽기가 맞아도 사용자가 있는 층이 아니다.
      → AI 가 "엘리베이터 안" 으로 보는 사진에서만 읽고, 로비 간판처럼 어두운
        판이 아닌 곳은 밝기 대비로 거르고, 지하("B1")는 따로 막았다.
      → 엘리베이터 앞 사진 230장에 돌려서 틀린 층 0장.

  [비상대피 안내판]
    제목 "공과대학 3호관 N층 비상대피 경로" 는 남색 바탕에 흰 글씨다.
    · 제목 띠만 잘라 흑백을 뒤집고 한국어 인식 모델로 한 줄을 읽는다
    · 띠가 파랑→검정 그라데이션이라 파란 부분만 잡힌다 → 어두운 칸을 따라 늘린다
    · "2층" 의 숫자가 "증" 처럼 뭉개지면 그 한 글자만 숫자 전용으로 다시 읽는다
    · 한국어 모델(1.1MB)은 안내판으로 보이는 사진에서만 내려받는다


────────────────────────────────────────────────────────────────
 3. 속도
────────────────────────────────────────────────────────────────

  번호판 읽기 : 1초 안팎 (PC)
  엘리베이터 층 표시 : 1초 안팎
  안내판 : 수 초 (한국어 모델을 처음 받을 때 더 걸린다)
  엘리베이터·안내판으로 보이는 사진은 예전의 무거운 단계(사진 전체·4조각 읽기)를
  건너뛰어, 엘리베이터 사진 한 장 판정이 44초 → 13초로 줄었다 (PC, 여러 시험을 동시에
  돌리던 상태). 폰에서는 더 걸릴 수 있어 폰 실측이 필요하다.

 4. 한계
────────────────────────────────────────────────────────────────

  · 번호판이 멀거나 비스듬하면 여전히 못 읽는다 (복도 60장 중 38장)
  · 엘리베이터·안내판 규칙은 모은 사진으로 다듬었으므로, 새 사진으로 한 번 더
    확인하는 게 좋다
  · 엘리베이터·안내판으로 읽은 층은 관리자 화면에 "층 확정" 으로 보이지만
    자동 승인은 하지 않는다 (후보 맨 앞에 놓고 관리자가 고른다)
