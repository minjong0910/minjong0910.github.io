왜 하나
  · 건의함 하루 3번 — 앱(폰 안 기록)만으로도 막히지만, 앱을 거치지 않고 서버에 바로 보내는
    장난까지 막으려면 서버가 「이 폰이 오늘 몇 번 올렸는지」 알아야 합니다.
    그래서 폰마다 이름·이메일 없는 번호(익명 로그인)를 하나씩 받게 했습니다. 개인정보는 모으지 않습니다.
  · 구성 및 변경 — 관리자가 고친 방 이름·번호·메모를 서버(rooms)에 둡니다.
    지금 서버 규칙은 그 밖의 모든 곳을 막아 두었기 때문에, 규칙을 새로 붙여야 저장·읽기가 됩니다.

!! 순서 : 1 → 2 → (새 앱 올리기) → 3 → 4
   앱은 옛 규칙·새 규칙 어느 쪽에서도 제보가 끊기지 않게 만들어 두었습니다.
   다만 3번(새 규칙)을 1번(익명 로그인 켜기)보다 먼저 하면 그동안 들어오는 제보가 폰에만 쌓입니다
   (나중에 저절로 다시 보내지긴 합니다).

----------------------------------------------------------------
1. 익명 로그인 켜기                                      (1분)
----------------------------------------------------------------
  왼쪽 메뉴 Authentication(인증) → Sign-in method(로그인 방법) 탭
  → [새 제공업체 추가] → 익명(Anonymous) → [사용 설정] 켜기 → [저장]

----------------------------------------------------------------
2. 「가입 막기」 설정 확인                                 (1분)
----------------------------------------------------------------
  9월 보안 설정 5번에서 Authentication → Settings(설정) → User actions(사용자 작업) 의
  「Enable create (sign-up)」 을 껐습니다. 이게 꺼져 있으면 **익명 로그인도 막힙니다.**
  → 「Enable create (sign-up)」 을 다시 켜고 [저장]
     (「Enable delete」 는 꺼 둔 채로 두세요)

  다시 켜도 괜찮은 이유 : 누가 계정을 만들어도 관리자가 되지 못합니다 — 관리자는
  admins 명단에 있는 사람뿐이고, 그 명단은 콘솔에서만 바꿀 수 있습니다(9월 보안 설정 2번).
  계정만 만든 사람이 할 수 있는 일은 익명 로그인과 똑같이 「하루 3번 제보」뿐입니다.

----------------------------------------------------------------
(새 앱 올리기)
----------------------------------------------------------------
  Claude 가 알려 드린 git push 명령을 실행합니다. 1~2분 뒤 사이트에 반영됩니다.

----------------------------------------------------------------
3. 새 규칙 붙여넣기                                       (1분)
----------------------------------------------------------------
  Firestore Database → 규칙 탭
  → 안에 있는 글자를 전부 지우고, D:\군산대\서버\규칙_붙여넣기용.txt 내용을 통째로 붙여넣기
  → [게시]
  (firestore.rules 와 내용이 같습니다. 메모장으로 열어 Ctrl+A → Ctrl+C)

----------------------------------------------------------------
4. 규칙 플레이그라운드로 시험                              (5분, 하면 좋음)
----------------------------------------------------------------
  Firestore Database → 규칙 탭 → [규칙 플레이그라운드(Rules Playground)]
  아래를 하나씩 넣고 [실행]. 결과가 표와 같으면 정상입니다. (날짜는 오늘 한국 날짜, 예 2026-10-18)

   #  시뮬레이션  위치(경로)                      인증                       결과
   1  get         /rooms/13115                   꺼짐                       허용 ○ (누구나 읽기)
   2  create      /rooms/13115                   켜짐 · UID 아무거나(abc)    거부 ✕ (관리자만)
   3  create      /suggestions/x                 꺼짐                       거부 ✕ (로그인 필요)
        문서 : {"u":"data:image/jpeg;base64,AAAA", "status":"pending"}
   4  get         /quota/abc_2026-10-18          켜짐 · UID = abc            허용 ○ (자기 것)
   5  get         /quota/zzz_2026-10-18          켜짐 · UID = abc            거부 ✕ (남의 것)
   6  update      /quota/abc_2026-10-18          켜짐 · UID = abc            거부 ✕ (줄이기 금지)
        문서 : {"n":0}   ← 플레이그라운드에 기존 문서가 없으면 「문서 없음」으로 거부돼도 정상
   7  get         /roomlog/x                     켜짐 · UID 아무거나(abc)    거부 ✕ (관리자만)

  「하루 3번」 자체(같은 일괄 쓰기에서 횟수를 올려야 함)는 플레이그라운드로 시험하기 어렵습니다.
  게시 뒤 폰으로 건의함에 사진을 4번 올려 보면 4번째에 「오늘은 3번 모두 올렸어요」가 뜹니다.
  (시험 제보는 관리자 화면 「건의함 검토」에서 거절하면 됩니다)
