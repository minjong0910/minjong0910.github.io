   1등 유사도 자체는 확신도가 못 된다 */
var CONF = { PLACE: 0.22, FLOOR: 0.16 };
function confTier(ai){
  if(!ai) return 'none';
  if(ai.codeSource === 'ocr' || ai.pickedByUser)
    return 'plate';
  var m = ai.margin || 0;
  if(m >= CONF.PLACE) return 'place';
  if(m >= CONF.FLOOR) return 'floor';
  return 'none';   // 모르면, 모른다
}

숫자가 거짓말을 할 때 — 네 번

01같은 사람이 찍은 사진이 섞였다

BEFORE
장소를 반으로 갈라 시험 → 같은 자리에서 연달아 찍은 사진끼리 맞혀 점수가 부풀었다
AFTER
사람 · 날짜 묶음으로 나눠, 다른 묶음의 사진으로만 시험

02기준과 질의의 전처리가 달랐다

BEFORE
기준은 원본, 앱은 1280px 사본 → 같은 사진인데 유사도 0.88 ~ 0.90
AFTER
양쪽 모두 같은 1280px 사본 · 224 축소는 직접 블록 평균 → 0.997

03모델 파일이 달랐다

BEFORE
PC에 둔 다른 모델 파일이 먼저 잡힘 → 같은 사진인데 유사도 0.54, 그 상태로 잰 값은 틀린다
AFTER
기준을 만든 것과 같은 모델만 쓴다 (정상 0.997)

04좋아 보이는 후처리

BEFORE
공통 성분을 걷어내는 후처리 → +0.4%p, 95% 구간 −1.3 ~ +2.0%p
AFTER
우연과 구분되지 않아 앱에 넣지 않음

배운 점과 남은 과제

LEARNED
  1. 정확도보다 「언제 답할지」가 먼저다 — 같은 AI로 55.6%와 92.9%가 갈렸다
  2. 100%는 먼저 의심한다 — 시험 자료가 기준에 섞이지 않았는지
  3. 이용자와 같은 조건으로 잰다 — 다른 사람이 찍은 사진, 같은 전처리, 같은 모델
  4. 측정 도구를 공개하면 숫자를 믿게 할 수 있다
