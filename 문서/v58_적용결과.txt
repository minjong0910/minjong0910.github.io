1. 무엇을 바꿨나
----------------------------------------------------------------
 (1) 전처리
     예전 : 사진 전체를 224x224 로 늘림(종횡비 깨짐) + 자동 명암보정
     지금 : 파란 표지판을 찾아 그 둘레만 잘라내기
            + 가운데 정사각 1.0 배율
            + 가운데 정사각 0.6 배율
            (종횡비 보존, 자동 명암보정 제거)
     표지판을 못 찾는 사진(약 9%)은 정사각 두 시점만 쓴다.

 (2) 후처리
     예전 : 제곱근 정규화
     지금 : 평균 빼기 + 제1주성분 제거
            모든 실내 사진이 공유하는 성분(복도·문짝·조명)을 걷어낸다.

 (3) 기준벡터
     사진 240장 x 시점 3개 = 698개를 새 방식으로 다시 계산.
     평균 벡터와 제1주성분을 파일 안에 같이 담았다(Float32).
     예전 방식으로 만든 벡터(자료집·학습분)는 섞이지 않게 걸러낸다.

 (4) 판정 문턱  ★ 가장 중요한 변경
     예전 : RELEVANT 0.65 / MATCH 0.72 / MARGIN 0.03 / SAME 0.99
     지금 : RELEVANT 0.15 / MATCH 9.99 / MARGIN 0.20 / SAME 0.97

     MATCH 를 닿을 수 없는 값으로 두어 AI 단독 자동 확정을 없앴다.
     AI 는 후보를 5개까지 제시하고, 확정은 번호판 OCR 이나 사용자가 한다.


2. 왜 자동 확정을 없앴나
----------------------------------------------------------------
 앱 주석에는 "MATCH 0.72 → 제보의 73%를 자동 확정하고 그중 정답 100%" 라고
 적혀 있었다. 이 값을 다시 재보니 이렇게 나왔다.

   측정 방법                                 Top-1   자동확정   정답률
   ---------------------------------------  ------  --------  ------
   시험 사진을 자료집에 그대로 두고 측정        100 %    100 %    100 %
   시험 사진을 후보에서 빼고 측정 (올바른 방법)   3.6 %     6.8 %      0 %

 예전 측정은 시험 사진이 이미 자료집에 들어 있는 상태였다.
 사진이 자기 자신과 같다는 것을 확인한 것뿐이라, 실제 사용과는 무관하다.

 사용자가 새로 찍은 사진에서는 자동 확정이 6.8% 발동하고 그중 맞는 것이 0% 였다.
 정확도 문제가 아니라 버그다. 그래서 없앴다.

4. 실제 앱에서 확인한 것
----------------------------------------------------------------
 사진 8장을 새 파일에 그대로 태워 보았다.

   정답        AI 1등      후보 5개                        판정
   ---------  ---------  ------------------------------  --------
   EV2        EV2        EV2,EV5,EV4,EV3,EVB1            맞음
   GATE_BACK  GATE_BACK  GATE_BACK,EV1,13419,...         맞음
   HALL3L     HALL4L     HALL4L,13523,HALL1L,...         층 틀림
   WC3        WC1        WC1,WC4,13226,WC5,B1            층 틀림
   13101      13524      13524,13225,13419,...           틀림
   13205      13402      13402,13403,13204,...           틀림

 눈여겨볼 점 — 장소의 "종류"는 정확히 맞힌다.
   화장실 사진의 후보는 WC1·WC4·WC5 로 전부 화장실,
   복도 사진의 후보는 HALL4L·HALL1L 로 전부 왼쪽 복도,
   엘리베이터 사진의 후보는 EV5·EV4·EV3·EVB1 로 전부 엘리베이터다.
   못 맞히는 것은 "몇 층인가" 뿐이다.

 이것이 창밖 사진이 필요한 이유다. 층마다 다른 것은 창밖 풍경뿐이다.

6. 아직 배포하지 않았다
----------------------------------------------------------------
 새 파일은 D:\군산대\index_new.html 이다.
 배포본 D:\군산대\index.html 과 GitHub 는 그대로 두었다.

 배포하려면
   1) 미리보기_실행.bat 을 켜고 http://localhost:8080/index_new.html 에서
      직접 써 보며 확인
   2) 괜찮으면 index_new.html 을 index.html 로 이름 바꾸고 GitHub 에 올리기

 되돌리려면 index.html 을 그대로 쓰면 된다. 아무것도 잃지 않았다.
