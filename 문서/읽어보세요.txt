공대 3호관 길안내 앱 — 작업 폴더 안내 (2026-09-22 새 구조)
================================================================

개발자용 자세한 설명은 README.md 에 있습니다 (GitHub 에서 저장소를 열면 첫 화면에 보입니다).
이 파일은 쉬운 말로 된 사용 안내입니다.

----------------------------------------------------------------
1. 폴더
----------------------------------------------------------------
  D:\군산대\
  ├─ site\              ← 앱. 이 폴더가 그대로 인터넷에 올라간다 (고칠 때는 여기 파일을 고친다)
  ├─ tests\             ← 자동 검사 (직접 열 필요 없음 — 검사_실행.bat 이 쓴다)
  ├─ 서버\              ← Firebase 보안 규칙과 콘솔 설정 안내
  ├─ 도구\              ← AI 자료 넣기 · 발표 PDF 만들기
  ├─ 문서\              ← 이 파일 · 측정 결과 · 한계와 대응 · 발표 자료 · 촬영 안내
  ├─ 미리보기_실행.bat   ← 내 PC 에서 앱을 열어 보는 창구 (더블클릭)
  ├─ 검사_실행.bat       ← 고친 뒤 올리기 전에 (더블클릭, 약 30초)
  ├─ eval_all.html 등    ← 정확도 측정 페이지 (미리보기 서버에서 연다)
  └─ README.md          ← 개발자용 설명

  예전 방식(index.html 한 파일 + 패치 스크립트 + 빌드.ps1)은 없어졌습니다.
  예전 파일은 git 기록에 모두 남아 있습니다.

----------------------------------------------------------------
2. 더블클릭으로 열면 기능이 안 됩니다
----------------------------------------------------------------
  site\index.html 을 더블클릭하면 주소가 file:///… 이 됩니다. 브라우저는 이 주소를
  '안전한 주소'로 쳐주지 않아서 카메라(QR) · AI · 번호판 읽기 · 서버 · 관리자 로그인이 전부 막힙니다.

    · 내 PC 에서 볼 때 : 미리보기_실행.bat 더블클릭 → 열리는 http://localhost:8080
    · 올린 뒤 볼 때    : https://minjong0910.github.io/

----------------------------------------------------------------
3. 고칠 때 순서
----------------------------------------------------------------
  ① 미리보기_실행.bat 을 켠다
  ② site\ 안의 파일을 고친다
  ③ 브라우저에서 http://localhost:8080 을 새로고침해 눈으로 확인한다
  ④ 검사_실행.bat — "검사 통과"가 나와야 올린다
     "실패"가 나오면 그 줄을 읽는다. 안전망(길안내·화면·3D 그림 비교)에서 걸리면,
     일부러 바꾼 것인지 확인하고 Claude 에게 "새 기준으로 기록해 줘"라고 한다.
  ⑤ 올린다 (4번)

----------------------------------------------------------------
4. 올리는 법
----------------------------------------------------------------
  2026-09-22 부터 파일이 여러 개(약 170개)라, GitHub 웹에 끌어다 놓는 방식 대신
  git 으로 올립니다. 올리면 GitHub 가 검사를 한 번 더 돌린 뒤 사이트를 바꿉니다.
  처음 한 번 GitHub 로그인이 필요합니다 — 방법은 Claude 가 안내합니다.

----------------------------------------------------------------
5. 관리자
----------------------------------------------------------------
  · 앱 첫 화면의 학교 그림(🏫)을 빠르게 5번 → 이메일 · 비밀번호
  · 관리자를 추가·교체하려면 서버\보안_설정_안내.txt 의 1·2번 (앱은 고칠 필요 없음)
  · 사진을 모든 사용자에게 보이게 하는 법 두 가지
      - 건의함 제보를 승인하거나 사진마다 '서버에 올리기' → 바로 반영 (서버에 저장)
      - 사진 관리의 '사진 자료 묶음(zip) 내려받기' → 압축을 site\ 에 풀고 올리기 (앱에 들어감)

----------------------------------------------------------------
6. 사진을 더 찍었을 때 (AI 자료 다시 만들기)
----------------------------------------------------------------
  ① 사진을 사진원본\<장소>\ 에 넣는다 (batches.json 에도 추가)
  ② 미리보기_실행.bat → http://localhost:8080/gen.html 「생성 시작」 (약 7분)
  ③ pwsh -File 도구\AI자료_넣기.ps1
  ④ 검사_실행.bat → 올린다
